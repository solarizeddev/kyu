Kyu Software

Install and remove software from your distribution's repositories, and Flatpaks.

Popular Applications

A short list of well-known programs, by category. Tick what you want and press Install; tick installed ones and press Uninstall. Greyed-out entries are installed already.

Repo

Every package in the repositories. "Hide library and developer packages" keeps the list to programs. Install and Uninstall show what pacman will do and ask before anything changes; pacman's own messages appear under Console Output.

Updates

Packages with a newer version are updated together with the whole system, never one by one: on Manjaro and Arch, updating a single package can break the programs that depend on the old one. "Upgrade All" runs Kyu's update (news first, keyrings first, explained failures) in its own window. Installing waits until the system is up to date.

Flatpak

Programs from Flathub, which is run by its own community. Turn the tab on in the settings.
