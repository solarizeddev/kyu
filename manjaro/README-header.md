# packageinstaller-manjaro

The package installer for [Manjaro](https://manjaro.org): a port of
[CachyOS's package installer](https://github.com/CachyOS/packageinstaller)
2.0. Browse, install, remove and update packages from the Manjaro
repositories, build AUR packages after reviewing their PKGBUILD (with a check
that marks risky lines), install Flatpak apps and AppImages, and pick a colour
theme. It shows Manjaro's name and logo and its own list of apps, and ranks
the mirrors with `pacman-mirrors`. The tray icon and update notifications come
from [update-notifier-manjaro](https://github.com/solarizeddev/update-notifier-manjaro).

What differs from CachyOS's version, how to build it and how upstream
releases are merged: [MANJARO.md](MANJARO.md).
