# Kyu's icons

The tray uses the icon theme's own update icons by name (`update-none`,
`update-low`, `update-medium`, `update-high`, `system-reboot-update`), so it
matches Breeze, Papirus or whatever theme is set.

Only "Updating" is Kyu's own: `kyu-updating-0` … `kyu-updating-23`, one
rotation frame each (15° apart, 1.5 s per turn), at 22 and 16 px, installed
into the hicolor theme. They are Breeze's `update-low` with its dot replaced by
a spinning arc, so they are derived from the Breeze icons (KDE, LGPL-3.0 or
later) and carry the same licence.
